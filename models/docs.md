# Аналитический слой интернет-магазина

Загрузчик переносит данные из PostgreSQL в схему `raw` базы `dwh` в Greenplum.

- `staging` приводит поля к удобны именам и типам, для того чтобы аналитик понимал, с чем работает
- `intermediate` джоинит таблицы, сложные преобразования и разворачивает дерево категорий
- `marts` содержит факты заказов и позиций, а также измерения клиентов, товаров и дат, он в целом уже содержит факты и измерения, данных с которыми работает потом работает BI аналитик 

Витрины позволяют анализировать подтверждённую выручку, продажи по категориям и долю покупателей по каналам привлечения, хах, строить отчет для финансового директора (было на работе..)
